# DarkGPT AI

AI Coding Assistant – Node.js 24

## Requirements

- Node.js 24+
- AI provider API key

## Setup

1. Copy `.env.example` to `.env`.
2. Fill in the AI API configuration.
3. Install dependencies:

   npm install

4. Run:

   npm start

5. Open:

   http://localhost:3000

## Deployment

Deploy on a Node.js hosting provider.

Do not expose your API key in public frontend code.
